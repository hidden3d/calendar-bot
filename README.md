# Hidden Calendar Bot — public information pages

Static Russian-language homepage and privacy policy for a personal Telegram bot that manages Google Calendar events.

- Homepage: https://hidden3d.github.io/calendar-bot/
- Privacy policy: https://hidden3d.github.io/calendar-bot/privacy/
- Terms of use: https://hidden3d.github.io/calendar-bot/privacy/#terms
- Support: reader.hid2@gmail.com

## Publication

GitHub Pages serves the root directory of the `main` branch. `.nojekyll` keeps the site buildless. HTML and CSS use relative links so the site works under `/calendar-bot/`.

Only informational website files belong in this public repository. The bot application has a separate repository and deployment.
